# Tableau Public

The dashboard screenshot in this folder demonstrates the visualization layer of the project.

**Important reproducibility note:** the Tableau workbook was developed from an Excel/CSV import that was in a different data state from the final MySQL analytical source. Therefore, the KPI values visible in the screenshot do not exactly match the SQL source-of-truth figures in the report.

For a final portfolio publication, connect Tableau to `data/credit_card_transactions.csv` (the canonical SQL-source dataset) and refresh the workbook so the dashboard reconciles with MySQL.
