# Data Dictionary

| Column | Description |
|---|---|
| transaction_id | Unique transaction identifier |
| customer_id | Synthetic customer identifier |
| transaction_date | Date of the transaction |
| transaction_amount | Transaction amount in INR |
| merchant_name | Merchant associated with the transaction |
| category | Merchant/transaction category |
| card_type | Synthetic card tier/type |
| city | Transaction city |
| gender | Synthetic customer gender field |
| birth_date | Synthetic customer date of birth |
| transaction_status | Approved or Declined |
| decline_reason | Reason recorded for declined transactions; blank for approved transactions |
